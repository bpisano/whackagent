# 0.30 · Lint

## Detect

## Plan

## Apply

1. Detect the tool (**lint → Tools**). Ask **wa-setup → Questions** 14.
2. No → add `lint: { tool: none, fix_command: "" }`, done.
3. Yes → `lint.tool: <tool>`, `fix_command: ""`, then **lint → Setup**.
4. Say: modules updated with `lint:` tags → accept their diffs in the sync rows below.
