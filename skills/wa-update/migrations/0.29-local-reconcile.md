# 0.29 · Local reconcile

`github` / `plane` only. Cards move from the plugin's Claude Code hooks (**store → Reconcile**), not a GitHub Action: no Actions minutes, no secret.

## Detect

Either:
- `.github/workflows/whackagent-board.yml` on `origin/<default branch>`
- `gh workflow list --all` shows `whackagent board` not `disabled_manually`

## Plan

`0.29 local reconcile : board Action disabled + removed (PR), cards caught up`

## Apply

1. `gh workflow disable whackagent-board.yml` — stops it on every branch at once, older task and sprint branches included.
2. File on default → branch `wa-update/local-reconcile` off default, `git rm .github/workflows/whackagent-board.yml`, commit (**git → Commits**), push, `gh pr create --assignee @me`.
   - Push refused for the `workflow` scope → user runs `! gh auth refresh -h github.com -s workflow`, push again.
   - Branch or PR already there → reuse, say so.
3. Secret `WA_PROJECT_TOKEN` / `WA_PLANE_TOKEN` in `gh secret list` → offer `gh secret delete <name>`. Ask: another workflow may use it.
4. `github` → **wa-setup → GitHub scaffold** 3 (merge workflow).
5. `board reconcile` → name each card moved (the Action may have missed some).
6. Say: merge the PR; nothing else to do per machine, the plugin update brought the hooks.
