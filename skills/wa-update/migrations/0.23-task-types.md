# 0.23 · Task types

Every task gets one type: `feature`, `improvement`, `bug`, `refactor` (**tasks → Types**).

## Detect

Open task (`draft`…`to-close`) with no type:
- `files` → no `type:` in its file
- `github` → `list` row with `type: null`, or no `WA_TYPE_LABELS` repo variable

## Plan

`0.23 task types : <n> typed from title, <m> to pick`

Ambiguous ones listed after it, one line each, recommended type first: `#44 Rework onboarding → improvement?`.

## Apply

1. `github`, no `WA_TYPE_LABELS` → `provision --project <n>` (labels created; `enhancement` → offer `--type improvement=enhancement`).
2. Each task, board order: type from the title verb, or the user's pick.
   - `files` → `type:` under `size:`.
   - `github` → `set-field <n> type <t>`.
3. `done`, `canceled` untouched. Titles never rewritten here.
