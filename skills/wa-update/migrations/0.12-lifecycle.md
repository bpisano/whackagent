# 0.12 · Lifecycle

`files` only. States say what's left to do, headings in English, sprints titled.

## Detect

Any `{tasks}/*.md` with:
- `status:` `in-progress`, `review` or `validated`
- a `grilled:` field
- a French heading (`## Contexte / Décisions`, `## Critères d'acceptation`, `## Implémentation`, `## Vérification`)
- a kebab-case `sprint:` (`login-refacto`)

## Plan

`0.12 lifecycle : <n> tasks + backlog rewritten`

Detail on demand: states, headings, sprints, titles, counts.

## Apply

Rewrite every matching task, then `{backlog}`.

- States: `in-progress` → `coding` · `review` → `to-test` · `validated` → `to-close` · `todo` + `grilled: false` → `draft` · + `true` → `todo`. Drop `grilled:`.
- Headings → `## Context / Decisions`, `## Acceptance criteria`, `## Implementation`, `## Verification` (**voice → Language**).
- Sprints: kebab → title (**voice → Titles**). Branches unchanged.
- Bad titles (**voice → Titles**) → rewrite, listed in the plan. Slugs, file names never move.
- Backlog: sections renamed + reordered (**tasks → States**), line order kept.
