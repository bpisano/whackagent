# Glossary

> whackagent convention module. One word per product concept, same word everywhere: UI strings, task titles, reports, PRs, and what Claude says to you. Yours to edit — every skill and both agents read it.

## Rules

- **One concept, one term.** Term listed here → use it, never a synonym from the `Never` column.
- **Everywhere.** UI strings (each language column), conversation, task titles and bodies, reports, PRs, wiki.
- **Code name** = identifier for that concept in source (`Trip`, `TripStore`). New type, file or variable for the concept → that name.
- **Missing term** → say it, propose the entry in one line, add only on yes. Never coin a second word for a concept already listed.
- Keep it short: concepts user sees or team argues about. Not a dictionary.
