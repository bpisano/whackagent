# Glossary

One word per thing, same word everywhere: UI, code, tasks, PRs, wiki. For whole team — agents read it too.

## Rules

- **One thing, one term.** Thing listed → use its term. Never a word from its `Never` column.
- **Code** = its name in source. New type, file or variable for it → that name. Existing code named otherwise → not renamed unasked.
- **Means** = one line, ≤ 12 words. More → link a wiki page.
- **New thing** → add a row. Agents propose rows, write them only on a yes.
- Short list: what users see or team argues about. Not a dictionary.
